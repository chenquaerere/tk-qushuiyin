TK去水印高清程序 v4.0.4 · 使用说明
====================================

【v4.0.4 本次更新】
- 修复「双击 exe 完全没反应」：少数机器（环境里同时有 NO_PROXY 和 no_proxy 两个
  变量）会让启动器在启动 Python 之前就抛异常。因为那段代码没有任何异常捕获，
  窗体还没显示、托盘还没建立，进程就静默结束了。
  现已去掉那两个多余的环境变量，并给整个启动流程加上异常捕获 ——
  以后再出问题会写进 launcher.log 并弹窗提示，不会再「什么都没发生」。
- 修复「设置 → 关于」里的更新日志只显示一行错误提示
  （（更新日志读取失败：module 'core.changelog' has no attribute 'get_changelog'））。
  原因是同一个函数被写了两遍，后面那份调用了不存在的接口，把正确的覆盖掉了。
- 顺手清理了两处同名的死代码函数。

【v4.0.3 本次更新】
- 高清修复的输入素材支持**一键清空**（清单顶部「🗑 清空」+ 素材区「🗑 清空列表」），
  不用再一个个点「移除」；任务进行中会拒绝清空并说明原因
- 顺手修掉一个更严重的问题：少数情况下所有文件都处理完了，任务却被判失败、
  一个结果都不显示。原因是「保存上次使用的参数」在多倍数字符串解析处抛异常，
  而这个动作发生在所有文件处理完之后，把整个任务拖成了失败。
  现已把倍数解析改为容错，并把参数记忆整体隔离 —— 它只是顺手记个偏好，
  以后无论出什么问题都不会再影响处理结果。

【v4.0.0 本次更新：从「网页应用」变成真正的桌面程序】

- 界面重设计为两大板块：左侧「① 去水印 / ② 高清修复」，
  下面依次是 模型中心 / 素材库 / 工具箱 / 设置 / 关于
- 底部新增任务栏，显示进行中的任务与总进度

【本次修复的重点问题】
- **高清处理时 cmd 黑窗一直闪** —— 已根治，处理全程 0 黑窗
  （原因：所有 ffmpeg 调用没传 CREATE_NO_WINDOW，一个视频会闪 3~7 次）
- **「双击没反应」的静默崩溃** —— 端口改为自动选择（7860~7879），
  启动失败会弹窗提示并指出日志位置；启动器加了作业对象，
  强杀启动器也不会残留进程占着端口
- **解析完成但看不到结果、下载按钮是禁用状态** —— 已修复
  （结果事件原先发在任务结束之后，前端收不到；
  现在解析完成默认全选，可直接点「下载选中」）
- **高清修复报「模型名,key」这样的错误** —— 已修复（前后端模型值对齐 + 兜底解析）
- **手机访问用不了** —— 已修复（之前监听地址被写死成 127.0.0.1）
- 视频转 GIF 文件名、抽帧计数、中文路径乱码、子线程异常丢失等一并修复

一、启动
1. 双击「TK去水印高清程序.exe」
2. 程序会打开**自己的窗口**（基于系统自带的 WebView2），不需要浏览器
3. 关闭：直接关闭程序窗口即可；或「设置 → 系统 → 退出程序」
4. 重复双击不会开出第二个窗口（单实例保护），会提示已在运行

   排查用启动方式：双击「启动-高清去水印.bat」
   （会保留黑色控制台窗口，方便看到启动错误和日志）


二、① 去水印板块

按三步走：

【① 粘贴链接】
- 粘贴 TikTok / 抖音 链接或分享口令（一行一条，自动提取链接、自动去重）
- 「📋 读取剪贴板」可直接填入；「🗑 清空」清掉输入与结果

【② 解析结果】
- 点「🔍 开始解析」，解析在后台进行，进度条与日志实时刷新
- 解析过程中可以随时取消
- 完成后会列出：序号 / 平台 / 类型 / 标题 / 作者 / 画质 / 时长
  图集会显示「图集(N)」，封面横条可预览
- **解析完成后默认全部勾选**；每行左侧勾选框，点整行也可以切换
- 也可以用「☑ 全选 / ☐ 全不选」批量操作
- 解析失败的链接会单独列在「解析失败项」里并给出原因

【③ 下载】
- 点「⬇️ 下载选中」开始下载
- 也可以在「按序号下载」里填 1,3-5 这种区间（留空则用上方勾选）
- 「下载后自动送入高清（仅图片）」勾上后，下载完可直接去高清板块处理
- 「⏸ 暂停 / ▶ 继续 / ⏹ 取消」随时可用
- 完成后「下载结果」区会出现：图片画廊、视频列表、文件清单，
  以及「📦 下载全部（ZIP）」（手机保存到相册推荐用 ZIP）
- 下方折叠面板「🕘 下载历史」可查看最近 100 条、刷新、清空

【为什么解析有点慢】
- tikwm 免费 API 限流是 1 请求/秒，程序按 1.15 秒/条排队，
  所以 3 条链接最少要约 4.5 秒，链接越多线性增长
- 解析结果有 45 分钟本地缓存：45 分钟内重复解析同样的链接会直接命中，明显更快

【解析失败原因对照】
- tikwm 限流：TikTok 免费 API 配额用尽，请稍后再试
- 代理失败：会自动直连兜底；若仍失败请检查网络
- 抖音风控：自动换签名重试，稍后再试
- 下载报「资源地址已过期（HTTP 403）」：签名直链过期，
  重新点一次「开始解析」拿新地址即可


三、② 高清修复板块

顶部有一排「场景预设」胶囊，点一下自动填好下方参数：
极速预览 / 均衡推荐 / 高清照片 / 人像特写 / 动漫插画 /
动漫视频 / 视频通用 / 极致画质 / 深度重建（规划中）

【输入素材】
- 把图片/视频**拖进虚线框**，或点「点击选择文件」
- 「📥 导入最近下载」：直接使用去水印刚下载的素材（在服务器磁盘上，不需要重新上传）
- 也可以填「文件夹路径」，会处理其中所有文件
- 已选文件在下方列出：
  · 清单最上方一行显示「共 N 个文件（x 个待上传，y 个已在服务器）」，
    右侧「🗑 清空」一次清掉全部（v4.0.3 新增）
  · 想只去掉某一个，点该行右侧的「移除」
  · 素材区的「🗑 清空列表」按钮作用相同，清单很长时不用往上滚（v4.0.3 新增）
  · 任务进行中会拒绝清空并提示原因，避免你以为清掉了、其实任务还在按原清单跑
  · 清空不会动「文件夹路径」输入框，清完可以马上改用文件夹跑

【处理参数】
- 模式：自动分流（图片+视频）/ 仅图片 / 仅视频
- 图片模型、视频模型：下拉里是中文名，实际提交的是模型标识（已对齐）
- 放大倍数：自动（推荐）/ 2x / 4x
- 视频档位：**仅锐化 1080p（最快，纯 ffmpeg，不调用 AI）** / 1920 / 2560 / 3840
- 输出长边上限：2048（最快）/ 4096（推荐）/ 8192（可能很慢）
- 人脸修复（会变慢）、视频补帧（60fps，较慢）
- 保存目录：留空则用「设置」里的输出目录

【处理】
- 点「开始处理」，可 暂停 / 继续 / 取消 / 打开输出目录
- 进度按阶段显示：抽帧 → 超分（逐帧）→ 编码
- 完成后「处理结果」区出现图片画廊与视频播放器，可直接预览或打开
- 说明：视频链路目前不含人脸修复（人脸修复仅作用于图片）

【效率提示】
- 源视频已经是 720p/1080p、只是想更清晰：选「仅锐化 1080p」最快
- 任务结束后程序会自动卸载模型并回收显存，连续换模型跑不容易爆显存


四、模型中心 / 素材库 / 工具箱

- 模型中心 → 模型库：按「超分 / 人脸 / 图像重建 / 视频重建」分类，
  每张卡片显示体积、显存占用、接入状态
- 模型中心 → 组合预设：9 组场景预设的参数一览
- 素材库：自动扫描下载目录与高清输出目录，缩略图 + 文件列表，
  可「打开输出目录」「清理临时文件」
- 工具箱：网络诊断、视频转 GIF、视频抽帧、批量重命名


五、手机 / 局域网访问（v4.0.1 起不需要登录）

1. 「设置 → 局域网 / 手机访问」勾选「允许局域网访问（手机）」
2. 点「📱 显示手机访问地址」，会显示形如 http://192.168.0.1:7860/ 的地址
3. **保存设置后重启程序**（监听地址在启动时确定）
4. 手机连接同一个 WiFi，用浏览器打开上面的地址 —— 直接进入，无需账号密码

注意：
- 端口是自动选择的（7860~7879），以设置页显示的为准，不要手输 7860
- ⚠ 开启后同一网络内的任何设备都能访问本程序（可解析、下载、查看输出目录里的结果文件），
  请只在可信网络（比如家里）开启，不用时建议把勾选取消
- 手机端已做适配：侧边栏转横向滚动、按钮加大到触摸友好尺寸、
  结果画廊两列、勾选框加大


六、设置

- 输出：图片/视频输出根目录、按日期建子文件夹、跳过已处理、保留临时抽帧、完成后提示音
- 高清参数：默认人脸修复、半精度、默认补帧、跳过近似帧、
  视频编码器（自动/NVENC/MF/x264）、CRF、切块 tile、人脸处理长边、各类上限
- 局域网 / 手机访问：见上一节
- 关于：运行环境、更新日志、打开输出目录、退出程序


七、常见问题

- 高清处理时窗口一直闪黑框：已在 v4.0 修复；若仍出现，请确认用的是新的 exe
- 解析完没有结果 / 下载按钮是灰的：
  v4.0.2 已修复。若界面还是老样子，关闭程序重新双击 exe
  （必要时在窗口里按 Ctrl+R 强制刷新一次）
- 高清处理完却没有结果、提示任务失败：
  v4.0.3 已修复（原因见本文件开头的 v4.0.3 说明）
- 双击 exe 完全没反应：v4.0.4 已修复。若仍遇到，看程序目录下的 launcher.log
- 「设置 → 关于」里更新日志只显示一行错误：v4.0.4 已修复
- 想一次清空已选文件：「输入素材」清单顶部的「🗑 清空」，或素材区的「🗑 清空列表」
- 处理很慢：高清超分依赖 GPU，没有独显会明显变慢；可换「极速预览」预设
- 照片想更锐：点「高清照片」预设（使用 4x-UltraSharp）
- 下载失败提示 403：签名直链过期，重新解析一次即可
- 找不到某个参数：多在「高级参数」折叠面板里，点开即可
- 端口被占用：程序会自动换端口（7860~7879）；若全部被占会弹窗提示
- 程序打不开 / 启动报错：查看程序目录下的 app.log 末尾；
  若是「双击没反应」，看 launcher.log（启动器自己的日志）


八、文件说明

- TK去水印高清程序.exe   启动器（双击这个）
- desktop.py              桌面版入口（原生窗口 + 本地服务）
- server/                 服务层（api / 业务内核 / 任务注册表）
- frontend/               界面（原生 HTML/CSS/JS）
- core/                   高清引擎（图片/视频超分、模型管理）
- tiktok/                 去水印（TikTok/抖音 解析与下载）
- tools/ffmpeg/           内置 ffmpeg（不需要另外安装）
- models/                 模型权重
- config.json             高清与局域网设置
- runtime/server.json     运行时端口文件（自动生成）
- app.log                 运行日志（出问题先看这里）
- launcher.log            启动器日志（只在启动失败时生成，v4.0.4）
- CHANGELOG.md            更新日志（由 core/changelog.py + scripts/gen_changelog.py 生成）
- 方案_v4.0_完整改造方案.md  v4.0 改造方案与施工记录
- scripts/smoke_test.py    冒烟自检（18 项，含倍数容错与清空列表）
- scripts/verify_frontend.py  前端行为验收（25 项，真实窗口 + 真实任务）
- _backup_v3.0.1_pre_v4.0_*/  改造前的源码快照（可回退）
